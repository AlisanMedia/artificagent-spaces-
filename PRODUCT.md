# ArtificAgent Spaces product context

Owner-directed local design refinement, 7 November 2026. The product is a Turkish-first real-estate media studio for agents and brokerage teams. The main task is to select a service, add permitted media, choose a small set of relevant options, then inspect the real result and its review state.

- `/spaces`: Operate. Upload and creation are primary; preserve every existing source/tenant/rights/job/review contract.
- `/spaces/showcase`: Experience with a clear route to the studio. Let actual sample media explain the service before the visitor uploads.
- The isolated static preview reuses public-safe presentation only. It has no private API, tenant database, real authentication or generation backend.

Four fixed video styles, image operations, a synthetic navigable 3D example and a licensed panorama exist. Public sample MP4s are local source-motion edits, not Kling/Seedance results. Several services have no verified output example. Preserve that distinction visibly. Do not fabricate before/after results, testimonials, prices, duration guarantees or user counts.

Current UI work does not activate providers, payment, production, Vercel or external services. The existing separate conditional V01 test authorization remains unchanged: one exact synthetic source/model/profile, 4 seconds, 16:9, 1920×1080 target, at most one paid submit and USD 10 total additional liability, subject to real access/secret/permit/terms/cost evidence. This design task does not execute that test.

Keep tenant RLS, private grants, immutable revisions, independent release review, consent, analytics, white-label and partner boundaries. Backend logic is outside this visual refinement. Existing main/PR2–4/Foundation acceptance protections remain; no new fifth PR or merge.
