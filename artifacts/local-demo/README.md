# Gerçek sentetik yerel örnekler

22 Ekim 2026; FFmpeg 7.1.5 / Blender 4.3.2, dış harcama 0 USD. MP4’ler gerçek H264/BT.709 dosyalardır; kaynak görsel pan/zoom/kesme demosu, fotogerçekçi AI POV değildir. GLB gerçek metrik parametrik mesh’tir; .json veya panorama değildir.

Ölçülen hash/boyut/süreler measured-results.json içindedir. Source illustration repository’deki sentetik SVG’den, plan sabit sentetik ölçülerden üretilmiştir. Gerçek adres/müşteri/konuşma/credential yoktur; audio yoktur. QA kararı iki yerel test kimliğiyle simüle edilmiştir, gerçek bağımsız insan incelemesi sayılmaz.

Serbest yürümek için uygulamada /spaces → Serbest 3D üretimi → ikinci test kimliği incelemesi → yerel tur kullanın. Alternatif npm run demo:local taze, süreli yerel linkleri **özel** .spaces-local/demo-evidence/session-links.json dosyasına yazar. O dosya ve signing key Git’e aktarılmaz. Bu artifact herhangi bir internet deployment değildir.
